SUPER LUCIAN WORLD 2D — REAL INSTRUMENTAL OVERRIDES
====================================================
Put MP3 files in a folder named  audio  next to index.html.
If a matching file exists, the game plays it on loop INSTEAD of the
built-in chiptune for that stage. Nothing to configure — just drop
the files in with these exact names:

PRIORITY (per-level files — use these for the exact track per stage):
  audio/11-b.mp3   FINAL BOSS — Prince, "Computer Blue" (instrumental) ★
  audio/1-1.mp3    First Pressing Plains — Queen (instrumental)
  audio/2-1.mp3    Purple Rain Falls — Prince, "Purple Rain" (instrumental)
  audio/4-1.mp3    Don't / Raincheck Streets — Bryson Tiller, "Don't" (instrumental)
  audio/8-6.mp3    Fortress 4X4 — seny, "4X4" (instrumental)
  audio/10-1.mp3   Views / The Tower — Drake, "Views" (instrumental)
  audio/2-b.mp3    Lord Monotone boss — Prince, "Bold Generation" (instrumental)
  audio/3-a.mp3    Baby Bowser Trump airship — Playboi Carti, "CRANK" (instrumental)
  audio/s-1.mp3    Little St. James — Flavour, "Ashawo - Remix" (instrumental)

FALLBACK (per-world files, used when no per-level file exists):
  audio/plains.mp3   audio/purple.mp3   audio/trapsoul.mp3
  audio/atlanta.mp3  audio/canopy.mp3   audio/boss.mp3
  audio/computer.mp3 audio/island.mp3

Use instrumentals you own or are licensed to use (purchased
instrumentals / beat-store licenses, your own rips of records you
own for personal play, or files you send Muse). The SOUND button
mutes MP3s and chiptune together.
